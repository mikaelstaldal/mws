# Mobile Web Shell — project administration

Specification, acceptance procedures and test evidence for
[Mobile Web Shell](https://github.com/mikaelstaldal/mws). The source code, build,
user documentation and website are in that repository.

- `spec/REQUIREMENTS.md`: functional requirements and acceptance criteria (what the app must do).
- `spec/ARCHITECTURE.md`: technical design, constraints, data model, test strategy and the provider compatibility rules (how it is built).
- `spec/ACCEPTANCE.md`: criterion-to-test traceability, device acceptance procedures and WebView provider qualification.
- `provider-evidence-*/`: raw reports from provider qualification runs.
- `acceptance-evidence-*/`: result logs and raw reports from device acceptance runs.

The provider compatibility matrix that the build reads is
`provider-compatibility.md` in the source repository.
